Widget 库 API 参考

APIGuideFAQ

WIDGET-API-MARKER 本文档描述 Widget 库的公开接口，包括初始化、渲染与销毁三个阶段。

初始化

调用 createWidget(options) 创建实例。options 支持 container、theme、locale 三个字段。

const w = createWidget({ container: '#app', theme: 'dark' })
w.render()

销毁

调用 destroy() 释放事件监听与 DOM 引用，避免内存泄漏。

  • destroy() 会解绑全部事件
  • 重复调用是安全的
