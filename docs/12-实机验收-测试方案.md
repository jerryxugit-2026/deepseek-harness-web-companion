## 0. 一条关键操作约定（决定"我能不能帮你看"）

我手里的 `browser_read / browser_ax / browser_screenshot / browser_tabs / browser_wait` **只在侧边栏面板打开时可用** —— 工具桥的那条 WS（`/ag/agent`）是由**面板文档**持有的，面板不开，插件直接回：

## 2. 人机配合层

格式：**你做什么 → 期望 → 失败长什么样 → 我这边怎么取证**。

### T1 · 打开侧边栏与认证（1 分钟）

- **你做**：点工具栏图标打开侧边栏 → 等它显示 DSH 界面。
- **期望**：面板顶栏状态点变绿、能看到 DSH 的输入框和会话列表；地址栏没有报错页。
- **失败**：白屏 / 只有 "连接 DSH…" / 顶栏红点。
- **我取证**：`browser_read` 读面板与 iframe 文本、`browser_screenshot` 截图。
- **保持**：**整个测试期间请让侧边栏开着**。

### T2 · 抓取主路径：面板「Attach 网页」（v3.38 重点）

- **你做**：随便开一个正常网页（例：`https://example.com`）→ 切回 DSH 面板 → 点 **「Attach 网页」**。
- **期望（新契约，这是本次修的那个现象）**：
  1. 状态栏出现「已附加：@网页捕获/….md」；
  2. **界面不跳走** —— 你还停在原来的会话上；
  3. **输入框是空的** —— 不会自动出现 `@网页捕获/…md`；
  4. 胶囊出现，上面除 ✕ 外还有 **「引用」**；如果你人在别的会话，会额外看到一条 **「去该会话」**；
  5. 工作区 `<workspace>/网页捕获/` 多一个 `.md`。
- **失败（=旧行为回来了）**：视图被切到一个新会话 / 输入框里自己出现了 `@文件` / 胶囊只有 ✕。
- **我取证**：`browser_ax`（看胶囊与它的按钮）、`browser_read`（看输入框是否为空）、审计日志那一行的 `trigger`/`sessionMode`、工作区文件。
- **对照**：点 **「引用」** → 应切到那个会话并把 `@文件` 插进草稿；点 ✕ → 胶囊消失且草稿不动。

### T3 · 抓取：选区（含负例）

- **你做**：在网页上划选一段文字 → 面板点 **「Attach 选区」**；然后**不选任何东西**再点一次。
- **期望**：第一次落盘文件里带引用块（`> **用户选区**`）；第二次**明确拒绝**（提示"没有检测到选区…"）且**不落盘**（旧缺陷是"没选就静默抓整页"）。
- **我取证**：两次落盘文件数对比 + 提示文案 + 审计日志。

### T4 · 抓取：右键菜单（v3.38 刚修 —— 以前 100% 坏）

- **你做**：在任意网页上**右键** → 点 **「Ask DSH about this page」**；再来一次右键 → 选「Ask DSH about selection」（先划一段字）。
- **期望**：面板被打开（右键手势会开面板）+ 状态栏「已附加」+ 落盘文件 front-matter 里 `trigger: manual`。
- **失败**：面板没反应 / 状态栏报错 / 没有新文件（旧行为：`E_PAYLOAD` 400，因为 `trigger: 'contextmenu'` 不在枚举里）。
- **我取证**：审计日志里应出现 `{"kind":"attach","trigger":"manual",…}`。

### T5 · 「看左边」自然语言全链路（保持不变的路径）

- **你做**：开着任意网页 → 在 DSH 输入框里**单独一行**写「看左边」→ **先别回车**，看瓶子。
- **期望**：① 面板状态栏「『看左边』→ 正在抓取…」→「已附加…」；② 你写的那句话**下面**自动多出一行 `@网页捕获/….md`（这条路径**故意**还是要预填的 —— 你是在这个会话里打的字）；③ 上方出现胶囊；④ 不新建会话、不跳走。
- **负例**：在正文里出现"看左边"三个字（不是行首）**不应**触发。
- **我取证**：`__AG_CLIENT__` 相关状态由 `probe:look-left-e2e` 已覆盖；实机里我看审计日志的 `trigger: look_left` + `sessionMode: current`。

### T6 · 胶囊生命周期

- **你做**：把 T2 或 T5 产生的胶囊 ✕ 掉。
- **期望**：胶囊消失；T5（`inserted`）情况下输入框里的 `@文件` **同时被移除**；T2（`offered`）情况下**草稿本来就没被碰**，所以什么都不该变。
- **我取证**：`browser_ax` 前后对比 + 审计 `{"kind":"ack","status":"dismissed"}`。

### T7 · 授权弹窗三分支（只有你能点）

> 需要先撤销授权：`chrome://extensions` → 本扩展 → 网站访问权限 → 改为「点击时」。

- **你做**：① 面板点「Attach 网页」→ 弹「读取所有网站」→ **允许**；② 再撤一次 → 点「Attach 网页」→ **取消**；③ 保持未授权，去抓一个不在 host 权限里的站点（如 `https://example.com`）。
- **期望**：①授予后状态栏「已附加」；②取消后提示"未授权：可在目标网页点一次扩展图标…"且**不落半截文件**；③要么走 `activeTab`（先在目标页点一次扩展图标），要么给出可操作提示，**不许静默失败**。
- **我取证**：三次的落盘文件数 + 面板文案截图。

### T8 · 反向控制（写操作三层闸门 + 调试横幅）

- **你做**：① 面板勾选 **「浏览器控制」**；② 让模型（或让我）调一次 `browser_click`；③ 取消勾选。
  - ⚠️ **横幅不是常驻**（2026-09-12 实测）：开关只是许可，attach 发生在每次操作内部（attach → 执行 → detach），横幅只在调用进行中出现（整页截图约 1s）。要观察就趁调用时盯着标签页顶部。
- **期望**：①面板提示已开启（横幅只在调用中出现）；②出现 **DSH 审批请求** → 批准则页面真的变、拒绝则工具报 denied 且页面不变；③取消勾选后写操作/调试器相关调用被拒（`E_NO_PERMISSION` 或 `E_READONLY`）。
  - **先看 `/ag/control` 的 `approvalMode`**：`ask` = 会弹提示（本机 2026-09-11 实测值）；`policy-never` = **本会话的审批提示被关掉了**，此时不弹窗、插件当场拒绝并说明是策略（v3.41 起；更早的版本会谎报 `ask` 并把拒绝甩锅给"用户拒绝了"）。
- **注意**：写工具默认**不注册**，需要面板上的「写操作」开关先打开（打开后能力集 5 → 8）；
  ⚠️ 该开关是**运行期**状态，`dsh web` 每次重启都会回到"关"（安全默认，需重新拨一次）；
  ⚠️ 若本会话的审批策略是 `never`（DSH 会明确告诉模型 "Approval prompts are disabled in this session"），则**不会有审批弹窗**：
  插件会当场拒绝并如实说明是策略 —— 此时"批准/拒绝两个分支"要换一个策略为 `ask` 的会话再跑（2026-09-12 实测）。
- **我取证**：`browser_tabs`/`browser_read` 页面变化 + 审计 `{"kind":"tool",…}`。

### T9 · 保留策略与防膨胀（你问的那件事）

- **你做**：在 `<workspace>/网页捕获/` 里放一个**你自己命名**的文件（例：`我的笔记.md`）；然后把某个**抓取文件**的 mtime 改成 25 小时前。
- **期望**：再抓一次之后 —— 你的文件**还在**；25h 的抓取文件**被删**；截图目录 `网页捕获/assets/` 走同一条清扫。
- **我取证**：文件清单 + `tests/unit/retention.test.mjs` + 审计里的清理计数。
