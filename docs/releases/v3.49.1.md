# v3.49.1 — new name, and a license

**(English / 中文 below)**

Two housekeeping changes before this project is shown to anyone else.

## Renamed

| | before | now |
|---|---|---|
| GitHub repo | `deepseek-harness-web-companion` | **`dsh-web-companion`** |
| Extension name | `DeepSeek Browser Companion` | **`DSH Browser Companion`** |

DeepSeek Harness's own [BRAND_GUIDELINES](https://github.com/deepseek-ai/deepseek-harness/blob/master/BRAND_GUIDELINES.zh.md)
asks third-party projects to use the **DSH** abbreviation in their *name*, and to describe the relationship
in prose instead ("built on DeepSeek Harness"). This repo was doing the opposite; that is fixed.

- **The extension ID does not change** — it is derived from the pinned `key` in the manifest (verified in the
  built artifact), so if you already loaded the extension you do not need to re-pair anything.
- GitHub redirects the old repo URL (repo page, releases, `archive` downloads) with a 301, so old links keep
  working.

## Licensed

Added **MIT** to match DeepSeek Harness: a new `LICENSE` file, `license: MIT` in all three `package.json`
files, and — the easy step to forget — `LICENSE` added to the installer's explicit payload list, so the
source package people download actually contains the license. A unit test now pins that.

No behaviour changes. `npm run check` is green.

# v3.49.1 — 改了个名字，补了许可证（中文）

在把这个项目拿给别人看之前，先做了两件清理。

## 改名

| | 原 | 现 |
|---|---|---|
| GitHub 仓库 | `deepseek-harness-web-companion` | **`dsh-web-companion`** |
| 扩展显示名 | `DeepSeek Browser Companion` | **`DSH Browser Companion`** |

DeepSeek Harness 自己的[品牌规范](https://github.com/deepseek-ai/deepseek-harness/blob/master/BRAND_GUIDELINES.zh.md)
要求第三方项目在**项目名**里用 **DSH** 缩写，关系写在描述性文字里（"基于 DeepSeek Harness 构建"）。
本仓库原来正好相反，现已改正。

- **扩展 ID 不变**（由 manifest 里钉死的 `key` 决定，已核对构建产物）⇒ 已经加载过扩展的用户不用重新配对。
- GitHub 会对旧仓库地址做 301 跳转（仓库页、release 页、`archive` 下载链接都包括），旧链接不会失效。

## 许可证

补上 **MIT**（与 DeepSeek Harness 一致）：新增 `LICENSE` 文件、三个 `package.json` 都写 `license: MIT`，
并且把 `LICENSE` 加进安装器的发行清单 —— 用户下载的是源码包，清单是显式白名单，不写进去等于包
里没有授权（这是最容易漏的一步）。现在有单测钉住它。

功能零改动，`npm run check` 全绿。
