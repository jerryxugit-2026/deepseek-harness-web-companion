# v3.47.1 — 发布包更干净，说明更好懂

**(English below / 中文在下面)**

A small patch release: the downloadable source archive no longer carries the project's internal design
documents, and the install instructions were rewritten for people who have never used GitHub.

## What changed

- **Internal documents are no longer in the download.** `详细设计文档.md`, `PRD_需求定义说明书.md`,
  `DESIGN.md`, `FINDINGS.md`, the ledger, the review notes and the research notes are excluded from the
  source archive via `export-ignore`. They stay in the repository for development; they are just not
  shipped to you any more.
- **Install instructions rewritten, click by click.** Download from **Releases** → this page → scroll to
  **Assets** → **`Source code (zip)`** (not the green Code button). The README also answers
  "do I have to compile anything?" — **no, the installer builds the extension for you** — and shows how
  to get the Terminal into the folder you just unzipped.
- **`.DS_Store` removed from the repository** (a macOS artefact that had been committed and shipped).

## Install

```bash
cd /path/to/deepseek-harness-web-companion-3.47.1
node bootstrap/install.mjs          # dry run: prints what it would change
node bootstrap/install.mjs --apply  # asks before every step
```

Then `chrome://extensions` → Developer mode → Load unpacked → the `extension/dist` folder the wizard built.

**Requirements**: macOS, Node 22+, Chrome. No compiler, no Xcode.

# v3.47.1 — 发布包更干净，说明更好懂（中文）

一个小补丁版本：下载包里不再带项目内部的设计文档；安装说明按"从没用过 GitHub 的人"重写。

## 改了什么

- **下载包里不再有内部文档**：`详细设计文档.md`、`PRD_需求定义说明书.md`、`DESIGN.md`、`FINDINGS.md`、
  台账、评审记录、研究笔记，都通过 `export-ignore` 从源码归档里排除；仓库里照旧保留（开发要用），

