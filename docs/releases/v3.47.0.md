# v3.47.0 — first public release

**English** · [中文](#中文)

An AI agent that sits next to the web page you are looking at, in the Chrome side panel: it reads the
page for you, and — when you turn that on — it also *works* the page. It runs on your own Mac, inside
[DeepSeek Harness](https://github.com/deepseek-ai). Nothing is sent to a third-party browser service.

Built because a ChatGPT browser extension was genuinely useful to me, many people in China cannot use
ChatGPT, and DeepSeek 4.1 Flash is both good and available here — but DeepSeek Harness had no such
extension.

## Install

Requires **macOS**, **Node 22+**, **Chrome**. Download the source above (or `git clone`), then:

```bash
node bootstrap/install.mjs          # dry run: prints what it *would* change
node bootstrap/install.mjs --apply  # asks you before every single step
```

Then open `chrome://extensions` → **Developer mode** → **Load unpacked** → pick the `extension/dist`
folder the installer just built, restart DSH (`dsh web`), and check everything:

```bash
node bootstrap/doctor.mjs
```

Full walkthrough: [`docs/13-installation.md`](../13-installation.md) (English) ·
[`docs/13-安装部署.md`](../13-安装部署.md) (中文).

**There is no pre-built extension in this release, on purpose.** The extension is built on your machine
with *your* port and *your* pairing key baked in; a pre-built copy would not work on your machine (and
shipping one by accident is a mistake this project has already made once).

## What is in it

- **Capture from the page** — the whole page as clean Markdown, just your selection, or a screenshot.
  Right-click menu, and a 「看左边」/ "look left" intent that grabs the page in the other tab.
- **Browser tools for the model** — read a page, list tabs, wait for something to appear, screenshot,
  read the accessibility tree.
- **Write operations behind an approval gate** — click, type, select, scroll, navigate. Every one is
  confirmed first; with the gate unsatisfiable, they are **refused** rather than silently allowed.
- **Local-first and quiet** — listens only on your own machine, no third-party service, pairing key +
  exact `Origin` match on both channels, pinned extension ID, a local audit log, and captures older
  than 24 h swept automatically.
- **A terminal wizard** — dry-run by default, asks before every change, verifies the result afterwards,
  and can repair or upgrade an existing install.

## This release's work

Mostly hardening the installer, found by six rounds of adversarial review (each finding verified before
it was acted on):

- **Fixed a dry-run hole**: the exit helper was asynchronous, so code after "stop" kept running — with
  `--yes` it could really create the install directory. It is synchronous now.
- **Uninstalling no longer deletes other plugins**: our entry used to share a `- insert:` block with
  neighbours, and removal took the whole block.
- **Upgrading no longer drops your settings**: keys you set earlier in your DSH profile are preserved.
- **Honest status**: health checks that never ran are no longer reported as passed; a fresh install that
  needs a DSH restart now exits with its own code (5) instead of "failed"; write operations refused by
  policy say so.
- **Dependency fallback**: if your DSH installation is missing a runtime package, the wizard downloads the
  one that is safe to download, and stops loudly on the ones that must match DSH exactly.
- **Versions are unified and gated**: `package.json`, the extension manifest, the plugin and the changelog
  all carry one number, and a test fails if they drift.

## Known limitations

- **Windows is not supported.** The installer says so and stops rather than pretending.
- No pre-built extension (see above); the build takes a few seconds locally.
- Seven smaller code-review items are known and recorded, not hidden: see the ledger
  (`docs/11-台账.md` §5 item 18).

# v3.47.0 — 第一个公开发布版本

一个 AI agent，就坐在**你正在看的网页旁边**（Chrome 侧边栏）：它替你读页面，在你打开开关时也替你**操作**页面。
它跑在**你自己的 Mac 上**、在 [DeepSeek Harness](https://github.com/deepseek-ai) 里，网页不需要交给任何第三方浏览器服务。

做它的原因：Chrome + ChatGPT 的插件对我来说确实好用，但**很多人在国内无法使用 ChatGPT**，
而 **DeepSeek 4.1 Flash 又好用、国内又能用** —— 可是 DeepSeek Harness 没有这样的扩展。

## 安装

需要 **macOS**、**Node 22+**、**Chrome**。下载上面的源码（或 `git clone`），然后：

```bash
node bootstrap/install.mjs          # dry run：只打印"打算"改哪些文件
node bootstrap/install.mjs --apply  # 真装：每一步都先问你
```

然后 `chrome://extensions` → **开发者模式** → **加载已解压的扩展程序** → 选安装器刚构建出来的
`extension/dist`，重启 DSH（`dsh web`），最后自检：

```bash
node bootstrap/doctor.mjs
```

完整步骤：[`docs/13-安装部署.md`](../13-安装部署.md)（中文） · [`docs/13-installation.md`](../13-installation.md)（English）。

**本版本故意不含预构建的扩展。** 扩展要在**你的机器上**构建，把**你的**端口与**你的**配对钥匙烤进去；
预构建的副本在你机器上跑不起来（而"不小心发了预构建产物"这个错，本项目已经犯过一次）。

## 这一版包含什么

- **从页面抓取** —— 整页压成干净的 Markdown、只抓你划中的选区、或截图。有右键菜单，
  也可以打「看左边」（或 "look left"）让它自己抓另一个标签页。
- **给模型的浏览器工具** —— 读页面、列标签页、等元素出现、截图、读无障碍树。
- **写操作走审批闸门** —— 点击、输入、选择、滚动、跳转，每一个都先经过你确认；
  闸门无法满足时**当场拒绝**，而不是偷偷放行。
- **本地优先、安静** —— 只监听你自己的机器、不经第三方服务、两条通道都要配对钥匙并精确匹配 `Origin`、
  扩展 ID 钉死、本机审计日志、超过 24 小时的抓取自动清理。
- **终端向导** —— 默认 dry-run、每改一处先问、装完自证，能修复/升级已有安装。

## 这一版做的事

主要是把安装器做硬，来自六轮对抗式审查（每条发现都**先验真再动手**）：

- **修掉一个 dry-run 漏洞**：退出用的辅助函数是异步的，于是"停下"之后的代码照样跑 ——
  带 `--yes` 时真会创建安装目录。现在是同步退出。
- **卸载不再删掉别的插件**：我们的条目原来和邻居共处同一个 `- insert:` 块，删除会连块一起摘。
- **升级不再丢你的设置**：你先前写进 DSH profile 的键会被保留。
- **状态诚实**：没跑过的健康检查不再被报成"通过"；刚装完需要重启 DSH 的情况有独立退出码（5），
  不再算"失败"；被策略拒绝的写操作会明说是策略。
- **依赖兜底**：你那份 DSH 里缺运行期包时，该下载的下载，**必须与 DSH 完全同源**的直接报错停下。
- **版本号统一且带门禁**：`package.json`、扩展 manifest、插件、CHANGELOG 共用一个号，漂了就红。

## 已知限制

- **不支持 Windows。** 安装器会明确说明并**当场停下**，不假装成功。
- 不含预构建扩展（见上），本地构建只需几秒。
- 还有 7 条较小的代码审查遗留项是**已知且记录在案**的，没有藏起来：
  见台账 `docs/11-台账.md` §5 第 18 项。
