# v3.48.2 — a real bug found by installing it on a real machine

**(English / 中文 below)**

Installing v3.48.0 end-to-end on a second Mac (unzipped to `/Volumes/Ex/ai_workspace/`, installed
in place) went through all 11 steps and the plugin came up paired — but the self-check reported:

```
❌ 扩展产物端口 == 真实配对端口 —— 未检查
      ↳ 缺 /Users/apexmini/.dsh/plugins/dsh-web-companion/scripts/check-dist-config.mjs
        （安装不完整）—— 重跑本引导程序补上
```

The install was complete. `doctor.mjs` was looking in the **old** default folder
(`~/.dsh/plugins/dsh-web-companion`) while the installer, since v3.47.2, installs into the folder you
unzipped. Two sources of truth for one thing: `doctor` produced a false red and told the user to re-run
the installer, and `uninstall.mjs` would have deleted the wrong path.

Both scripts now default to the folder the package itself lives in — the same value the installer uses —
and `defaultInstallDir()` (the old path) is deleted from `bootstrap/lib/layout.mjs`, so the concept
exists in exactly one place. A wiring bug that only shows up at runtime (`install.mjs` still imported the
deleted helper; `node --check` cannot see that) was fixed as well.

New regression test (`tests/unit/install-behavior.test.mjs` section 7): runs `doctor.mjs --json` and
`uninstall.mjs` and asserts both default to the package folder and never print the old path. Reverting
either default reddens 2 assertions; with the fix all 47 pass.

Install: download `Source code (zip)` for v3.48.2 and follow `README.md` — the wizard checks your machine,
tells you the exact command for anything missing, and writes nothing until you pass `--apply`.

# v3.48.2 — 在真机上装了一遍，抓到一个真 bug（中文）

在一台 Mac mini 上把 v3.48.0 完整装了一遍（解压到 `/Volumes/Ex/ai_workspace/`，原地安装）：11 步全过、
插件已配对，但自查脚本报"**安装不完整 —— 重跑本引导程序**"。安装其实是完整的 ——
`doctor.mjs` 去**旧的**缺省目录 `~/.dsh/plugins/dsh-web-companion` 找东西，而安装器从 v3.47.2 起
装的是"你解压出来的那个文件夹"。同一件事两个真源：doctor 产生假红并误导用户，`uninstall.mjs`
则会去删错的目录。

现在两个脚本的缺省值都改成**本包所在的目录**（与安装器一致），并把旧路径的
`defaultInstallDir()` 从 `bootstrap/lib/layout.mjs` 里删掉 —— 这个概念只剩一处。
顺带修掉一处只有跑起来才暴露的接线问题（`install.mjs` 还在导入那个已删除的函数，
`node --check` 看不到）。

新增回归测试（`tests/unit/install-behavior.test.mjs` 第 7 节）：跑 `doctor.mjs --json` 与 `uninstall.mjs`，
断言两者缺省都等于本包目录、且不再打印旧路径。把任一缺省值退回旧写法 ⇒ 2 条断言立刻变红；
修好后 47 条全绿。

安装：下载 v3.48.2 的 `Source code (zip)`，按 `README.md` 走 —— 向导先体检、缺什么给你确切的安装命令，
不加 `--apply` 不会写任何文件。
